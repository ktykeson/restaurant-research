How to get a Google Places API key
  1. Open the Google Cloud Console and sign in with your Google account.
  2. In the top bar, click the project dropdown (next to "Google Cloud") → New Project. Give it a name like "Restaurant Research" and click Create. Make sure the new project is selected in the dropdown.
  3. Go to Billing and link a credit card to the project. Google's free monthly credit covers most light usage, so you typically won't be charged.
  4. Open Places API (New) in the API Library and click Enable. Wait for it to finish.
  5. Go to APIs & Services → Credentials, click + Create Credentials at the top, then choose API key.
  6. A popup shows your new key starting with AIza…. Click the copy icon, then paste it into the field above and press Save & continue.
